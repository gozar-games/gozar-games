# GOZAR BATTLE ARENA

این پوشه بازی مستقل Battle Arena است و نباید منطق یا فایل‌های Crossy Road را تغییر دهد.

## فایل فعلی
- `index.html`: نمونه اولیه قابل اجرا با Canvas، کنترل لمسی، دشمن‌ها، موج‌ها، خشاب، سپر و جعبه‌های مهمات/سلامتی.

## کنترل‌ها
- موبایل: جوی‌استیک سمت چپ برای حرکت؛ روی محیط بازی لمس/کشیدن به سمت هدف برای نشانه‌گیری؛ دکمه آتش را نگه دارید تا شلیک پیوسته انجام شود.
- رایانه: WASD یا کلیدهای جهت‌دار برای حرکت؛ کلیک روی محیط برای نشانه‌گیری؛ Space برای شلیک؛ R برای تعویض خشاب؛ Shift برای سپر.

## وضعیت توسعه
این نسخه هنوز نمونه اولیه سمت کاربر است. ذخیره ابری، اتصال تلگرام، کمپین، باس‌ها، فروشگاه، ارتقای دائمی، آنلاین چهارنفره و اعتبارسنجی ضدتقلب هنوز پیاده‌سازی نشده‌اند.

## ترتیب کار فنی پیشنهادی
1. تکمیل و تست کنترل‌ها و برخوردها در موبایل و دسکتاپ.
2. جداسازی منطق بازی به فایل‌های مستقل (ورودی، موجودیت‌ها، موج‌ها، رابط کاربری).
3. افزودن مرحله کمپین و باس‌ها.
4. طراحی API سمت سرور برای حساب بازیکن و سکه‌ها؛ موجودی و پاداش‌ها باید سمت سرور اعتبارسنجی شوند.
5. ذخیره‌سازی ابری با شناسه تلگرام.
6. آنلاین خصوصی چهار نفره پس از تثبیت حالت تک‌نفره.

## محدودیت انتشار
این شاخه برای توسعه است. تا زمان تست و تأیید، آن را با `main` ادغام یا روی نسخه اصلی منتشر نکنید.
